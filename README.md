# Lily Dash

A Cookie Run–style runner for Lalynn: Lily runs along a pirate pier through six sea areas,
jumps, flips and slides past sea monsters, answers Math, English, Science and Thai questions
at quiz gates, and beats a boss at the end of each area by answering correctly.

Play: https://kiki057.github.io/lily-dash/  (on iPad: Share → Add to Home Screen)

- Questions and progress are shared with Lily Card Voyage through Cloud Save (family code).
- Works offline after the first visit.
- Built with Godot 4.3 (web export, no threads).
